controls

Each location can have unlimited connectors.

Use add_connector repeatedly, or double-click near any edge of a location to create one exactly there.

Drag any orange connector onto another connector to link them. You can also drop onto the body of another location and a new connector will be created automatically at that point.

Connected connectors are automatically repositioned onto the routing grid. If a connector is already in use, creating another link from it automatically creates a separate routed connector.

Drag a location card to reposition it. Every tile is locked to the grid. Tiles cannot overlap other tiles or established link routes. Accepted links use exclusive orthogonal grid routes, so links cannot cross or overlap each other or pass through tiles. If a move or link cannot satisfy those rules, it is rejected.

The canvas is unbounded: drag empty space to pan in any direction. Use the mouse wheel to zoom.
